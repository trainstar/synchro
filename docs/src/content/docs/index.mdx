---
title: Synchro
description: PostgreSQL-to-SQLite synchronization for Swift, Kotlin, and React Native applications.
---

Synchro synchronizes PostgreSQL data with local SQLite databases.
Native applications can keep working offline and synchronize through an authenticated HTTP adapter.

The PostgreSQL extension owns server-side synchronization.
Swift and Kotlin own the local database and durable synchronization work.
React Native exposes those clients through a native bridge.

## Start with a working example

Follow [First synchronization](/synchro/getting-started/quickstart/) to edit a note offline and verify it on PostgreSQL and another client.

The guides describe `0.3.0`.
Use the [local-consumer installation](/synchro/clients/consumption/) before that release is available.
The [support policy](/synchro/reference/support-policy/) distinguishes supported environments from development hosts.
