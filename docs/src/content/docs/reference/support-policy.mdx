# Support Policy

## v0.3.0 Matrix

The public v0.3.0 verification matrix is deliberately narrow:

| Surface | Required environments |
| --- | --- |
| Server | PostgreSQL 18 only |
| Apple client | iOS 16 and current stable iOS |
| Apple client | macOS 13 and current stable macOS |
| Android client | Android API 24 and current stable Android API |
| React Native bridge | React Native 0.83.x on iOS 16 and current stable iOS |
| React Native bridge | React Native 0.83.x on Android API 24 and current stable Android API |

PostgreSQL 14, 15, 16, and 17 are excluded from v0.3.0 verification. Existing build features or incidental successful use do not expand the public matrix.

The React Native package supports `react-native >=0.83.0 <0.84.0` and the compatible React 19 line. React Native verification exercises both the iOS and Android bridge paths over the native SDKs.

## Minimum And Current Tracks

Minimum tracks protect the declared deployment floor: iOS 16, macOS 13, and Android API 24. Current tracks protect compatibility with the current stable Apple and Android platform releases available when an RC begins.

`current-stable` is an authored policy selector, not a permanent version number. The RC manifest resolves it to exact operating system, Xcode, Apple SDK, Android SDK, emulator or simulator, and supporting toolchain versions. Those exact values remain fixed for that candidate and appear in generated evidence.

## Required Policy Is Not Certification

This page and `conformance/support-matrix.json` state which cells are required or excluded. They do not claim that a release candidate has passed those cells.

Certification requires generated, immutable evidence from the release workflow for every required cell, tied to one candidate commit and exact artifact hashes. A version is not added to a release claim merely because it is expected to work, has a compile-time feature, or passed an unrelated development test.

See [Verification Overview](/synchro/verification/overview/) for how evidence is produced and [Release Verification](/synchro/spec/07-release-verification/) for the normative gate.
