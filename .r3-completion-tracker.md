### 2026-09-08: R3.2 And R3.3 Complete

The live soak passed on the desktop against real PostgreSQL at commit `74e67ac`.

- `TestSoak/live`: 917 seconds, every planned operation executed, zero violations.
- `TestSoak/checksum-corruption-replays-from-seed`: 51 seconds. The corrupted run failed with `checksum-convergence.wire-row-digest-mismatch`, and the replay from the recorded seed reproduced the identical violation.
- Structured result: 3 tests passed, zero failures. Gate `make test-conformance-invariants`: 124 tests passed.

Defects the live run found and fixed, each at its cause:

- The harness sent the whole connect-response schema object. The contract type decodes strictly, so every request was invalid.
- The setup rebuilt before its first pull, but scope subscriptions bind through the pull path.
- A returning connect omitted `client_generation`, which `extensions/synchro-pg/src/client.rs:183` requires.
- Mutations carried a UUID `client_version` instead of the canonical microsecond timestamp `extensions/synchro-core/src/contract.rs:782` requires.
- Engine defect: `mutation-conservation` required a UUID `client_version`, contradicting the contract. The rule was authored against a wrong assumption and passed every fixture review. Only real bytes exposed it. The rule and its fixtures now follow the contract.
- `ConfigForDuration` modeled 16 operations per second, which is unrunnable for live operations that wait on WAL materialization and process restarts.
